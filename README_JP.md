## 📦 Windowsパッケージのインストール

1. このページのダウンロードボタンから `setup.zip` を取得します。
2. エクスプローラーで `setup.zip` を右クリックし、**すべて展開**を選びます。
3. 展開先を開いて `setup.exe` を実行し、インストーラーの案内に従います。



<a name="section-3"></a>

## 🛟 動かないときの確認項目

| 症状 | 確認すること |
| --- | --- |
| クリック位置がずれる | ウィンドウ位置と表示倍率 |
| リールのタイミングが違う | 検出設定と釣り竿の設定 |
| 更新後に失敗する | ゲーム画面と解像度の変更 |

入力マクロ、executor用スクリプト、釣り竿計算ツールは別の種類です。すべてが付属するとは限りません。動作した設定を残し、テスト時の解像度と釣り竿を記録しておきましょう。

<a name="section-4"></a>

### ⚙️ Fischマクロの自動釣りがずれるとき

解像度やWindowsの表示倍率を変更したら、認識範囲を調整し直します。自動リールのタイミングも、使用する釣り竿で短くテストしてください。
