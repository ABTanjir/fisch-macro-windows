## 📦 Windows 패키지 설치

1. 이 페이지의 다운로드 버튼으로 `setup.zip`을 받으세요.
2. 파일 탐색기에서 `setup.zip`을 마우스 오른쪽 버튼으로 클릭하고 **모두 압축 풀기**를 선택하세요.
3. 압축을 푼 위치에서 `setup.exe`를 실행하고 설치 안내를 따르세요.



<a name="section-3"></a>

## 🛟 작동하지 않을 때

| 증상 | 확인할 항목 |
| --- | --- |
| 엉뚱한 위치 클릭 | 창 위치와 화면 배율 |
| 릴 조작 타이밍 오류 | 감지 설정과 낚싯대 설정 |
| 업데이트 후 실패 | 게임 UI와 해상도 변경 |

입력 매크로, executor 스크립트, 낚싯대 계산기는 서로 다른 도구입니다. 모두 포함되어 있다고 가정하지 마세요. 정상 작동한 설정을 보관하고 시험 당시의 해상도와 낚싯대를 기록하세요.

<a name="section-4"></a>

### ⚙️ Fisch 자동 낚시 매크로가 빗나갈 때

해상도나 Windows 배율을 바꿨다면 인식 영역을 다시 맞추세요. 자동 릴 타이밍은 사용할 낚싯대로 짧게 시험한 뒤 조정하세요.
