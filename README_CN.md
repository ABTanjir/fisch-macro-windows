## 📦 安装 Windows 软件包

1. 通过本页下载按钮获取 `setup.zip`。
2. 在文件资源管理器中右键点击 `setup.zip`，选择**全部解压缩**。
3. 打开解压后的位置，运行 `setup.exe`，按安装程序提示操作。

## 🛟 宏不生效时怎么排查

| 现象 | 检查内容 |
| --- | --- |
| 点击位置偏移 | 窗口位置、显示缩放。 |
| 收杆时机错误 | 识别设置、鱼竿配置。 |
| 更新后失效 | 游戏界面与分辨率变化。 |

键鼠宏、需要执行器的脚本和鱼竿计算器属于不同类别，不应把它们默认视为同一个安装包的功能。保留已经可用的配置，并记录测试时的分辨率和鱼竿，方便后续复现。

<a name="section-4"></a>

### ⚙️ Fisch 自动钓鱼不识别进度条怎么办？

修改分辨率或 Windows 缩放后，重新校准识别区域。自动收杆的时机也需要结合当前鱼竿进行短时间测试。
