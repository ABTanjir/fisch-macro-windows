## 📦 Instalar el paquete para Windows

1. Descarga `setup.zip` con el botón de esta página.
2. En el Explorador de archivos, haz clic derecho en `setup.zip` y elige **Extraer todo**.
3. Abre la ubicación extraída, ejecuta `setup.exe` y sigue el instalador.



<a name="section-3"></a>

## 🛟 Cuando el macro no pesca

| Síntoma | Qué revisar |
| --- | --- |
| Clic fuera del botón | Posición de ventana y escala de pantalla. |
| Recogida a destiempo | Detección y configuración de la caña. |
| Fallo tras una actualización | Cambios de interfaz o resolución. |

Un macro de entradas y un script para executor son categorías diferentes. Tampoco debe darse por incluido un calculador de cañas. Guarda la configuración que funcionó e identifica cada prueba por su resolución y caña.

<a name="section-4"></a>

### ⚙️ El macro de Fisch no detecta la barra

Tras cambiar la resolución o la escala de Windows, vuelve a calibrar la captura y el auto reel. Descargar un macro de Fisch no configura automáticamente la caña ni los tiempos de reacción.
