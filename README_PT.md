## 📦 Instalar o pacote para Windows

1. Baixe `setup.zip` pelo botão desta página.
2. No Explorador de Arquivos, clique com o botão direito em `setup.zip` e escolha **Extrair Tudo**.
3. Abra o local extraído, execute `setup.exe` e siga o instalador.



<a name="section-3"></a>

## 🛟 Corrigir pelo sintoma

| Problema | Verificação |
| --- | --- |
| Clica no lugar errado | Janela movida ou escala alterada. |
| Erra o momento de recolher | Detecção, interface e configuração da vara. |
| Parou após atualizar | Mudanças do jogo e configurações antigas. |

Macro de teclado e mouse, script de executor e calculadora de varas são ferramentas diferentes. Não presuma que o pacote reúna todas elas. Guarde os ajustes que funcionaram e registre a resolução e a vara de cada teste.

<a name="section-4"></a>

### ⚙️ Macro de Fisch errando o auto reel

Recalibre a área de captura depois de mudar a resolução ou a escala do Windows. Teste os tempos com a vara escolhida antes de deixar várias tentativas em sequência.
