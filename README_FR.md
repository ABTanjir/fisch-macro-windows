## 📦 Installer le paquet Windows

1. Téléchargez `setup.zip` avec le bouton de cette page.
2. Dans l’Explorateur de fichiers, faites un clic droit sur `setup.zip`, puis choisissez **Extraire tout**.
3. Ouvrez le dossier extrait, lancez `setup.exe` et suivez le programme d’installation.



<a name="section-3"></a>

## 🛟 Corriger un dysfonctionnement

| Symptôme | Point à vérifier |
| --- | --- |
| Clic au mauvais endroit | Position de fenêtre et mise à l'échelle. |
| Mauvais timing | Détection et configuration de la canne. |
| Échec après mise à jour | Interface du jeu et réglages précédents. |

Une macro d'entrées, un script pour executor et un calculateur de cannes ne désignent pas la même chose. Aucun de ces ajouts n'est présumé inclus. Conservez les réglages fonctionnels, avec la résolution et la canne utilisées lors du test.

<a name="section-4"></a>

### ⚙️ Régler le macro Fisch et l’auto reel

Après un changement de résolution ou de mise à l’échelle Windows, recalibrez la zone de détection. Testez ensuite les délais avec la canne utilisée.
