## 📦 安裝 Windows 套件

1. 使用本頁下載按鈕取得 `setup.zip`。
2. 在檔案總管中以滑鼠右鍵點選 `setup.zip`，選擇**全部解壓縮**。
3. 開啟解壓縮後的位置，執行 `setup.exe`，依安裝程式指示操作。



<a name="section-3"></a>

## 🛟 依症狀檢查

| 狀況 | 檢查項目 |
| --- | --- |
| 點擊位置不對 | 視窗位置與顯示縮放。 |
| 收竿時間不準 | 偵測設定與釣竿配置。 |
| 更新後不能用 | 介面與解析度是否改變。 |

輸入巨集、executor 腳本和釣竿計算器是不同工具，不能因為名稱含有「輔助」就假定全部提供。保留已經可用的設定，並記錄測試時的解析度與釣竿，方便日後重現。

<a name="section-4"></a>

### ⚙️ Fisch 巨集自動收竿失準

調整解析度或 Windows 顯示比例後，重新校準辨識範圍。再配合使用中的釣竿測試自動收竿時機。
